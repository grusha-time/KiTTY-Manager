# Если что-то не работает

Сначала определите, что именно не получилось: открыть SSH, пройти через JH, открыть сайт, передать файл или выполнить задачу. Один успешный этап не доказывает остальные.

## Быстрые проверки

| Симптом | Что сделать |
|---|---|
| Менеджер не сохраняет настройки | Полностью распакуйте ZIP в папку с правом записи; проверьте, что запускаете нужную копию exe |
| Не находится ключ | Проверьте локальный путь и доступ к файлу. Относительный путь считается от папки приложения |
| Connection refused | Проверьте адрес, порт и запущенную службу; увеличение таймаута не открывает закрытый порт |
| Connection timed out | Проверьте сеть/VPN, доступность JH, адрес в данном контексте и firewall; затем таймаут/зонд |
| Authentication failed / Permission denied при входе | Проверьте логин, SSH-пароль/ключ, passphrase и разрешённые сервером методы |
| JH открылась, цель недоступна | Проверьте готовность SOCKS5, команду доступа и маршрут к цели; консоль сама по себе не доказывает готовность |
| Отказ port forwarding | На промежуточном сервере может быть запрещён проброс; нужны подходящие настройки/права, а не другой цвет связи на карте |
| Выбран сервер другой сети с тем же IP | Уточните «Маршрут через», подтверждённые направления и резервные внутренние адреса |
| После полного выхода оборвалась консоль | Этот маршрут обслуживал менеджер. Для фоновой работы сворачивайте его в трей |

## Firefox

**Исходный профиль не найден или неполон.** Запустите обычный Firefox, дождитесь создания профиля и закройте его. При ручном выборе указывайте саму папку профиля с `key4.db` и `cert9.db`, а не каталог программы Firefox.

**Источник занят.** Закройте Firefox и его фоновые процессы, использующие этот профиль. Не удаляйте lock-файл работающего браузера. Для диагностики полезен отдельный исходный профиль с минимальным набором настроек.

**Нет новых сохранённых логинов после повторного открытия.** Изменения временного веб-профиля не синхронизируются обратно. Подготовьте нужные данные в исходном профиле заранее.

**Не разрешается имя панели.** Проверьте домен/порт URL. При необходимости укажите его реальный внутренний IP в «Адресе DNS». Пустое поле не означает автоматическую подстановку SSH-адреса сервера.

**Ошибка HTTPS.** Проверьте домен в сертификате, время и доверие цепочке. Не приравнивайте ошибку сертификата к ошибке SSH-туннеля.

## Конструктор задач

- Для обязательного условия используйте **Check**, а не просто Command. Ненулевой результат обычной команды может быть предупреждением.
- Если «Если → То» не проверяется повторно, это ожидаемо для одинаковой команды условия: результат кешируется на сервер на время запуска.
- Если файл отличается и передача запрещена, посмотрите режим backup. Не включайте замену до проверки назначения.
- Если диалог ждёт текст, сравните ожидаемую подстроку с реальным stdout/stderr, включая регистр. Проверьте, не открыта ли программа в другой консоли.
- Если после отправки ответа шаг пишет об отсутствии маркера завершения, программа могла остаться работающей. Проверьте её результат отдельно.
- Снятие отметки действия в списке не является отключением шага при запуске. Отметки нужны для операций со списком; для пропуска используйте условие или удалите ненужное действие из копии задачи.
- Если итог «исчез», включите все уровни и отключите «Только вывод консоли» в «Виде журнала».
- При занятом Local-порте выберите свободный порт и назначьте туннель ровно одному серверу.
- После обрыва читайте вопрос о повторе: команда могла уже изменить сервер. Для первых испытаний используйте обратимые операции и отдельную папку.

## Ansible

1. Выполните **«Проверить готовность Ansible»** и посмотрите этап ошибки.
2. Если отсутствует runtime/повреждён hash, заново распакуйте целый дистрибутив. Не смешивайте QEMU/образ/manifest из разных сборок.
3. Если недоступна виртуализация/WHPX, настройте соответствующий компонент Windows по диагностике и требованиям своего компьютера. Это не исправляется установкой Python на Windows.
4. `localhost` — VM. Windows-файл должен передаваться через `kitty_manager_windows_files`, а результат — через `kitty_download_dir`.
5. Missing role/collection: сохраните папку playbook с зависимостями целиком. Runtime не выполняет автоматический Galaxy install. Текстовый предварительный сканер может ошибочно принять буквальный IP с двоеточием за имя коллекции; URL из переменных избегает этого случая.
6. Для большинства модулей нужен Python на целевом Linux. Существование Python внутри VM не устанавливает его на удалённый сервер.
7. Для Vault нужен пароль Vault, для become — реальные права и правильная SSH/root-учётная запись.
8. Для разбора playbook повысьте подробность, сохраните журнал и проверьте его перед передачей другим людям.

## Что приложить к сообщению об ошибке

Версию и способ запуска приложения, точное действие, ожидаемый/фактический результат, исходный текст ошибки и соответствующий участок журнала. Для задачи — минимальную обезличенную копию её описания и шаг, на котором произошёл отказ. Не нужны полный config, открытый JSON-экспорт, закрытые ключи или личные профили Firefox.
