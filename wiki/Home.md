## Краткий обзор

KiTTY Manager решает задачу доступа к серверам, к которым нет прямого подключения:

```
Ваш компьютер → JH (точка входа) → Сервер A → Сервер B → Целевой сервер
```

Менеджер:
- Хранит дерево сессий (группы/подгруппы)
- Импортирует существующие KiTTY-сессии
- Строит граф связей между серверами
- Автоматически выбирает лучший маршрут
- Открывает SSH-консоли через KiTTY
- Открывает веб-интерфейсы через Firefox + SSH-туннель

## Стек

- **Язык:** C# (.NET 8.0)
- **GUI:** WPF (Windows-only)
- **SSH:** SSH.NET 2025.1.0
- **Шифрование:** DPAPI (Windows Data Protection API)
- **KiTTY:** 0.76.1.13 (форк PuTTY)
