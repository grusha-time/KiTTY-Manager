# Веб-панели Firefox Containers и SFTP WinSCP

Веб-панели используют постоянный профиль менеджера и изолированные контейнеры Firefox. Обе интеграции используют доступ к сети выбранной SSH-сессии. Установите Firefox (требуется версия **128 или новее**) и WinSCP отдельно, если они нужны; исполняемые файлы этих приложений в ZIP менеджера не входят. Отдельная установка расширения Mozilla Multi-Account Containers не требуется: менеджер автоматически разворачивает собственное расширение **KiTTY Manager Containers**.

## Контейнеры Firefox и постоянный профиль

Исходный Firefox нужно закрыть только один раз перед первым копированием профиля. Рабочая папка хранится в `Data/FirefoxContainers/profile`. Исходный личный профиль пользователя не изменяется.

- **Изоляция:** каждый веб-интерфейс получает свой изолированный контейнер (`userContextId`) и собственный KiTTY-туннель. Cookies и локальные данные сайтов разделены между контейнерами.
- **Сохранение данных:** новые сохранённые пароли и добавленные исключения сертификатов остаются в общем постоянном профиле менеджера (`Data/FirefoxContainers/profile`) между запусками. Обратной синхронизации в личный профиль ОС нет.
- **Маршрутизация трафика:** сетевые запросы внутри контейнера направляются через локальный relay сессии. Запросы, обрабатываемые расширением вне настроенного туннеля, блокируются. WebRTC разрешён напрямую через сеть ОС в обход SOCKS-туннеля.
- **Наследование вкладок:** при нажатии кнопки «+» или `Ctrl+T` из активной вкладки контейнера новая вкладка автоматически открывается в том же контейнере с тем же туннелем и прокси. Это позволяет открывать соседние адреса и порты в той же сети без потери связности.
- **Повторное открытие:** повторное открытие той же записи веб-панели переиспользует уже существующий контейнер и активный туннель.
- **Самоподписанные сертификаты:** по умолчанию включена настройка «Автоматически принимать самоподписанные SSL-сертификаты». Предупреждения безопасности («Принять риск и продолжить») автоматически пропускаются через управляющую сессию Marionette (параметр `acceptInsecureCerts`), а в профиле активируется доверие системным корневым сертификатам ОС (`security.enterprise_roots.enabled = true`). При выключенной настройке Firefox использует стандартный строгий режим с ручным подтверждением исключений.
- **DNS:** URL и таблица DNS/IP работают через локальный relay выбранной сессии с сохранением Host/SNI. Поле логина/пароля в менеджере остаётся подсказкой, а автозаполнением паролей управляет сам Firefox.

## Управление полями и контекстным меню таблицы

- **Показ и скрытие пароля:** кнопка-«глаз» в столбце «Пароль» доступна всегда, в том числе в режиме просмотра таблицы без входа в режим редактирования ячейки.
- **Копирование значений:** через контекстное меню ПКМ доступен пункт **«Копировать значение поля»**, который копирует в буфер обмена значение конкретной выбранной ячейки (название, URL, адрес DNS, логин или пароль) без необходимости входа в режим редактирования.
- **Контекстное меню при редактировании:** при редактировании ячейки (включая поля «URL» и «Пароль») по правому клику мыши открывается тёмное контекстное меню поля с возможностью отмены, вырезания, копирования, вставки и выбора всего. Правый клик в редактируемом поле не завершает процесс редактирования.

## Оптимизация дискового пространства

Для предотвращения разрастания профиля при работе с множеством сессий и туннелей реализованы 5 мер оптимизации (все включены по умолчанию в настройках):
- **Перенос кэша в оперативную память:** отключает дисковый кэш (`browser.cache.disk.enable = false`) и выделяет RAM-кэш (`browser.cache.memory.enable = true`, `browser.cache.memory.capacity = 51200`), экономя до 80–90% размера профиля без потери кук и паролей.
- **Отключение баз SafeBrowsing:** исключает загрузку бинарных баз фишинга/вредоносных сайтов для туннельных адресов (экономия 50–80 МБ).
- **Отключение сбора истории и иконок:** предотвращает раздувание баз `places.sqlite` и `favicons.sqlite` при обращении к временным локальным портам туннелей (до 50 МБ).
- **Очистка кэша при закрытии браузера:** автоматическая санитаризация кэша на выходе с сохранением авторизаций, кук и сессий.
- **Очистка данных удалённых серверов:** при удалении сессии или веб-интерфейса из менеджера ассоциированный контейнер удаляется через `browser.contextualIdentities.remove`, очищая изолированные cookies, IndexedDB и localStorage.

## Завершение работы и туннели

- Служебные окна KiTTY, поднимающие туннели под веб-панели Firefox, запускаются сразу свёрнутыми на панель задач Windows (`ProcessWindowStyle.Minimized`), не перекрывая рабочий стол. При необходимости окно туннеля можно развернуть кликом по его кнопке на панели задач.
- При включённой настройке **«Закрывать консоль веб-туннеля после закрытия Firefox»** консоль KiTTY и маршрут автоматически завершаются после закрытия последней вкладки соответствующего контейнера.
- По умолчанию эта настройка выключена: служебная консоль KiTTY остаётся запущенной на панели задач и отвязывается от отслеживания. Повторное открытие веб-панели создаёт новый туннель, а оставленную консоль требуется закрывать вручную.
- При полном выходе из Firefox, потере связи с расширением или закрытии KiTTY Manager все активные (ещё отслеживаемые) веб-туннели завершаются принудительно. Профиль `Data/FirefoxContainers/profile` не удаляется.

## SFTP через WinSCP

1. Установите WinSCP либо задайте путь к `WinSCP.exe` в настройках. Пустое поле означает автоматический поиск.
2. Выберите сессию и **«Открыть в WinSCP»**. Менеджер строит маршрут и передаёт временный локальный порт.
3. Если внешнее приложение спрашивает host key, сверьте отпечаток. Host key не является вашим закрытым ключом.
4. Работайте с файлами, затем закройте окно WinSCP. Маршрут освобождается после завершения соответствующего процесса.

Права SFTP определяются SSH-учёткой; наличие команды sudo/su в карточке не означает, что WinSCP автоматически получит root-доступ к файлам. В текущей реализации пароль/passphrase передаются аргументами WinSCP — это не скрытый от ОС канал секретов.

## Если не открывается

- **Расширение Firefox не отвечает:** связь bridge с запущенным процессом Firefox потеряна или не установилась за время ожидания. Закройте все открытые окна Firefox и повторите запуск.
- **Постоянный профиль занят:** предыдущий экземпляр Firefox всё ещё работает и удерживает блокировку файлов профиля (`Data/FirefoxContainers/profile`). Завершите процесс Firefox; не удаляйте lock-файлы вручную при работающем браузере.
- **Профиль не найден:** запустите обычный Firefox один раз для создания профиля по умолчанию либо укажите путь к папке профиля вручную в настройках.
- **Сайт не найден:** проверьте URL, домен, DNS/IP-сопоставление и доступность веб-порта через SSH-сессию.
- **Ошибка сертификата:** при выключенной настройке автопринятия подтвердите исключение вручную («Принять риск и продолжить»); сверьте доменное имя в URL, дату и сертификат; работоспособность SSH не доказывает доверие HTTPS.
- **WinSCP не найден:** проверьте путь к исполняемому файлу WinSCP в настройках.
- **SFTP permission denied:** проверьте права SSH-пользователя на целевом сервере и путь к файлу.
