# Веб-панели Firefox и SFTP WinSCP

Обе интеграции используют доступ к сети выбранной SSH-сессии. Установите Firefox/WinSCP отдельно, если они нужны; исполняемые файлы этих приложений в ZIP менеджера не входят.

## Веб-панель: подготовка

1. Запустите обычный Firefox один раз, чтобы он создал рабочий профиль. В нём можно заранее сохранить нужные логины и допустимые исключения сертификатов.
2. В настройках менеджера выберите путь к Firefox. Автопоиск профиля читает `profiles.ini`; при ручном выборе нужна исходная папка с `key4.db` и `cert9.db`.
3. Закройте Firefox, использующий исходный профиль, перед его копированием.
4. В таблице веб-интерфейсов сессии добавьте имя и полный URL, например `https://panel.example.test:8443/`, затем сохраните изменения.
5. Откройте панель. Менеджер подготовит маршрут, отдельную консоль веб-туннеля и временную копию профиля.

Временные профили разделены между открытиями. Они получают начальные данные из источника, но **не синхронизируют изменения обратно**. Новые пароли и принятые исключения сертификатов из временного окна потеряются при удалении его копии. Если нужно сохранить такие данные для следующих открытий, подготовьте их в исходном профиле отдельно.

Поле «Шаблон профиля Firefox» в интерфейсе означает исходный профиль. Пересоздания общего накопительного шаблона и общего профиля группы в текущем режиме нет.

## URL, DNS и пароль

| Поле | Пример | Смысл |
|---|---|---|
| Название | Панель приложения | Подпись строки |
| URL | `https://panel.example.test:8443/status` | Схема, домен/IP, порт и путь сайта |
| Адрес DNS | `192.0.2.20` | Явное соответствие домена из URL адресу для этого подключения |
| Логин / пароль | Ваша учётная запись сайта | Подсказка; менеджер не заполняет форму автоматически |

Пустой «Адрес DNS» оставляет обычное разрешение DNS/hosts. Заполненный IP используется внутренним механизмом подключения; системный файл hosts не переписывается. Для HTTPS сохраняйте правильное доменное имя в URL, если сертификат выпущен на него: замена URL на IP может дать ошибку сертификата.

Параметры управляемого прокси записываются в копию профиля. Не исправляйте их вручную во временном Firefox как основной способ настройки — при следующем открытии будет другая копия.

## Закрытие

Не закрывайте отдельную консоль KiTTY веб-туннеля, пока пользуетесь страницей. Настройка закрытия этой консоли после Firefox по умолчанию выключена. Полный выход из менеджера завершает его маршруты. Занятые файлы профиля могут задержать уборку; не удаляйте папку работающего браузера вручную.

## SFTP через WinSCP

1. Установите WinSCP либо задайте путь к `WinSCP.exe` в настройках. Пустое поле означает автоматический поиск.
2. Выберите сессию и **«Открыть в WinSCP»**. Менеджер строит маршрут и передаёт временный локальный порт.
3. Если внешнее приложение спрашивает host key, сверьте отпечаток. Host key не является вашим закрытым ключом.
4. Работайте с файлами, затем закройте окно WinSCP. Маршрут освобождается после завершения соответствующего процесса.

Права SFTP определяются SSH-учёткой; наличие команды sudo/su в карточке не означает, что WinSCP автоматически получит root-доступ к файлам. В текущей реализации пароль/passphrase передаются аргументами WinSCP — это не скрытый от ОС канал секретов.

## Если не открывается

- **Профиль не найден:** откройте обычный Firefox или выберите готовую папку вручную.
- **Профиль занят:** закройте использующий его браузер; не удаляйте lock-файлы живого процесса.
- **Сайт не найден:** проверьте URL, домен, DNS/IP-сопоставление и доступность веб-порта через сессию.
- **Ошибка сертификата:** сверьте имя URL, дату и сертификат; работоспособность SSH не доказывает доверие HTTPS.
- **WinSCP не найден:** проверьте путь exe.
- **SFTP permission denied:** проверьте права SSH-пользователя и сам путь файла.
