# Веб-интерфейсы

## Обзор

Для каждой SSH-сессии можно добавить веб-интерфейсы, которые открываются через SSH-туннель в отдельном временном Firefox-профиле.

## Настройка

В карточке сессии → раздел **Веб-интерфейсы** → **Добавить**:

| Поле | Описание |
|------|----------|
| Название | Произвольное имя |
| URL | Полный адрес, например `https://192.0.2.20:8443/` |
| Логин | Подсказка (Firefox не подставляет автоматически) |
| Пароль | Подсказка (Firefox не подставляет автоматически) |
| Резолвить домен по адресу | Отдельный IP для этого интерфейса (пусто = адрес сессии) |

## Firefox-профили

- Для каждого открытого веб-интерфейса создаётся **отдельный временный профиль**
- Системный proxy не меняется
- Профиль удаляется после закрытия окна
- Постоянные профили запоминают сертификаты и настройки сайта

## Внутренний DNS

По умолчанию **выключен** — Firefox использует системный DNS/`hosts`.

При включении:
- Менеджер создаёт локальный HTTP/HTTPS-прокси для Firefox
- Настроенные домены направляются через SSH-маршрут
- Остальные сайты открываются напрямую
- Системный `hosts` не требуется
- Параметры Firefox «Отправлять DNS через прокси» остаются выключенными

### Безопасность

- Локальный proxy использует HTTP CONNECT
- HTTPS до целевого сайта остаётся **сквозным** — менеджер не расшифровывает
- Исходный URL, имя сайта и HTTPS-проверка не меняются

## Туннели

- Для каждого веб-туннеля выбирается отдельный свободный локальный порт
- Веб-интерфейсы разных сетей (даже с одинаковыми внутренними IP) работают одновременно
- Туннель живёт внутри менеджера — для сохранения закрывайте окно в трей
