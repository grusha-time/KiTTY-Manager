# Веб-панели Firefox Containers TEST и SFTP WinSCP

В этой тестовой ветке веб-панели используют один постоянный профиль и контейнеры.
Подробные инструкции, ограничения и проверки: [FIREFOX-CONTAINERS-TEST.md](../FIREFOX-CONTAINERS-TEST.md).

Исходный Firefox нужно закрыть только перед первым копированием. Рабочая копия хранится
в `Data/FirefoxContainersTest/profile`. Новые пароли и сохраняемые риски остаются там;
исходный личный профиль не меняется. Один контейнер соответствует паре ID сессии и веб-интерфейса.
Каждый контейнер получает собственный KiTTY-туннель; повторное открытие той же записи
использует существующий контейнер и туннель. Группы не определяют маршрутизацию.

URL и таблица DNS/IP работают через локальный relay выбранной сессии с сохранением Host/SNI.
Поле логина/пароля менеджера остаётся подсказкой, а сохранёнными паролями управляет Firefox.
После закрытия последней вкладки контейнера туннель закрывается при включённой настройке.
Полный выход менеджера отключает активные контейнерные подключения, профиль не удаляется.

## SFTP через WinSCP

1. Установите WinSCP либо задайте путь к `WinSCP.exe` в настройках. Пустое поле означает автоматический поиск.
2. Выберите сессию и **«Открыть в WinSCP»**. Менеджер строит маршрут и передаёт временный локальный порт.
3. Если внешнее приложение спрашивает host key, сверьте отпечаток. Host key не является вашим закрытым ключом.
4. Работайте с файлами, затем закройте окно WinSCP. Маршрут освобождается после завершения соответствующего процесса.

Права SFTP определяются SSH-учёткой; наличие команды sudo/su в карточке не означает, что WinSCP автоматически получит root-доступ к файлам. В текущей реализации пароль/passphrase передаются аргументами WinSCP — это не скрытый от ОС канал секретов.

## Если не открывается

- **Профиль не найден:** откройте обычный Firefox или выберите готовую папку вручную.
- **Профиль занят:** закройте использующий его браузер; не удаляйте lock-файлы живого процесса.
- **Сайт не найден:** проверьте URL, домен, DNS/IP-сопоставление и доступность веб-порта через сессию.
- **Ошибка сертификата:** сверьте имя URL, дату и сертификат; работоспособность SSH не доказывает доверие HTTPS.
- **WinSCP не найден:** проверьте путь exe.
- **SFTP permission denied:** проверьте права SSH-пользователя и сам путь файла.
