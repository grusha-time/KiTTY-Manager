# Экспорт / Импорт

## Экспорт

**… → Экспорт JSON…**

Перед экспортом показывается таблица сессий:
- Выбор всех или части сессий
- Исключение точек входа и настроек jumphost

### Что попадает в файл

| Включено | Не включено |
|----------|-------------|
| Сессии + веб-интерфейсы + секреты | Настройки приложения (пути, таймаут) |
| Ветки групп с выбранными сессиями | TOTP-секреты точек входа |
| Связи (оба сервера выбраны) | |
| Резервные адреса | |

> ⚠️ JSON-экспорт содержит пароли **открытым текстом**. Храните в защищённом месте.

## Импорт

**… → Импорт JSON…**

- Текущая конфигурация **не стирается**
- Новые объекты добавляются
- Совпадения показываются таблицей конфликтов
- Для каждого конфликта: оставить текущее / принять из файла (или сразу для всех)
- Локальные пути KiTTY/Firefox импорт не заменяет

## Перенос на другой компьютер

1. Экспорт JSON на старом компьютере
2. Установка менеджера на новом
3. Импорт JSON
4. Настройка локальных путей (KiTTY, Firefox)
5. Настройка TOTP-секретов точек входа (не переносятся)

## Резервное копирование

Экспорт JSON — основной механизм бэкапа. Рекомендуется:
- Создавать перед крупными изменениями
- Хранить в защищённом месте
- Не отправлять через незащищённые каналы
