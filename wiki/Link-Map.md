# Карта связей

## Открытие

**… → Карта связей…**

Показываются только сессии, у которых есть хотя бы одна сохранённая связь.

## Обозначения

| Элемент | Значение |
|---------|----------|
| Синяя линия | Подтверждённый успех хотя бы одного направления |
| Оранжевая пунктирная | Связь сохранена, но успешного состояния нет |
| Жёлтые дуги | Связи выбранной сессии |
| Жёлтая рамка | Карточки, связанные с выбранной |

Два направления одной пары объединяются в одну линию.

## Управление

| Действие | Эффект |
|----------|--------|
| Перетаскивание пустого места | Двигает карту |
| Колесо мыши | Масштаб |
| Кнопки `−` / `+` | Масштаб |
| «Вся карта» | Автоматический масштаб |
| Клик по карточке | Выбор сессии в главном окне |

## Раскладка

- Карточки размещаются с гарантированным зазором
- Периферийные узлы ставятся снаружи рядом со своими связями
- Совпадающие линии расходятся
- Прочие линии приглушаются при выборе сессии

## Проверка связей с карты

1. Нажмите **Проверка связей**
2. Отметьте ≥ 2 сессии:
   - Кликом на карте
   - Через выпадающий список с поиском (список не закрывается при выборе)
3. Нажмите **Проверить выбранные**

Менеджер проверит каждую выбранную пару одним проходом. Успешные результаты появятся на обновлённой карте.

Настройка «В режиме карты проверять только новые связи» (вкл. по умолчанию) пропускает уже сохранённые пары.

## Построение внутри группы

ПКМ по группе → **Построить карту связей внутри группы…**

- Проверяет каждую пару до первого успеха
- Пары с подтверждённым входным сервером завершаются первыми
- Зависимые пары запускаются после и используют найденные связи
- Если первое направление недоступно — пробует обратное
- Успех сохраняет обе направленные записи
- Отказ инвалидирует обе

### Опорный сервер

Если до сервера группы уже сохранён рабочий маршрут через другие сессии:
- Менеджер открывает цепочку один раз
- Из опорной SSH-сессии проверяет остальные серверы
- Одинаковые длинные входы не запускаются параллельно

### Недостающие связи

**Построить только недостающие связи…** — исключает пары с хотя бы одной сохранённой записью. Удобно после добавления одной новой сессии в большую группу.

## Сохранённые связи

Кнопка **«Сохранённые связи…»** показывает для выбранной сессии:

- Единый список связанных серверов в дереве групп
- Состояние каждой связи
- Возможность проверить все последовательно
- Удаление связей (по одной или несколько, с флажками)

Если отмечена ровно одна подтверждённая связь — кнопка **«Подключиться через выбранную связь»** строит маршрут через отмеченный сервер (только для одного запуска).
