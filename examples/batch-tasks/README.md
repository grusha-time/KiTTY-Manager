# Примеры массовых задач

[Руководство: запуск, создание задач, особенности Ansible и дополнительные проверки](../../wiki/Batch-Tasks.md).

- **Конструктор:** откройте [`task-safe-smoke.kmtask`](task-safe-smoke.kmtask). Все файлы уже внутри. Редактируемый исходник — [`constructor/task.yaml`](constructor/task.yaml).
- **Ansible:** сохраните всю папку [`ansible/`](ansible/), откройте [`ansible/ansible-safe-smoke.yml`](ansible/ansible-safe-smoke.yml). Соседние материалы обязательны.

Откройте **«Массовые задачи»**, выберите нужный режим и один тестовый сервер. Затем используйте пошаговую инструкцию руководства. После успеха повторите на нескольких разных серверах.

Обычный запуск рассчитан на тестовый Linux с Python 3 и не требует root. Для конструктора также нужны SSH/SFTP, `tar` и `gzip`. Туннели, повышение прав, Windows upload и Vault включаются по инструкции. Эти примеры проверяют выполненные сценарии, а не весь менеджер.

После изменения исходников конструктора обновите ZIP `.kmtask` (внутри должны лежать `task.yaml` и `files/`, без внешнего каталога). Из корня репозитория запустите существующие self-tests. Проверка «Учебные задачи» сверяет пакет с исходниками, все типы действий и перенос материалов Ansible:

```sh
dotnet run --project src/KiTTYManager.SelfTest/KiTTYManager.SelfTest.csproj
```

Проверка комплектности примеров не запускает SSH или VM; другие offline-тесты могут использовать локальный loopback-стенд. Итог реального запуска смотрите в журналах и выгруженных файлах по руководству.


## Как понять результат

- Конструктор: финальный `CONSTRUCTOR_SMOKE_OK`, успешный итог сервера и `result.txt` с `constructor=PASS` в Downloads.
- Ansible: успешный `ANSIBLE_SMOKE_OK`, отсутствие итоговых failed/unreachable, `summary.json` с PASS. Флаг `false` в summary означает, что дополнительная проверка не включалась.
- Ожидаемый exit 7 в учебном сценарии должен быть обработан продолжением/rescue; остальные ошибки требуют разбора.

Временные тестовые папки и очистка описаны в руководстве. После обрыва или остановки очистка может не завершиться. Примеры не требуют реальных имён организаций, регионов или секретов разработчика.
